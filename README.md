#  Кинокаталог (ДЗ 14)

Полнофункциональное React-приложение с авторизацией, офлайн-режимом, кешированием и маршрутизацией.

 ##  Функционал

###  Авторизация (Задание 1)
- [x] Форма входа с полями: email, пароль
- [x] Валидация: email (формат), пароль (≥6 символов)
- [x] Запрос к API (POST /login), получение JWT-токена
- [x] Сохранение токена в `localStorage`
- [x] Проверка токена при загрузке приложения
- [x] Защищённые маршруты через `<ProtectedRoute>`
- [x] Перенаправление на `/login` при отсутствии/истечении токена
- [x] Кнопка «Выйти»: очистка токена + редирект

###  Service Worker (Задание 2)
- [x] Файл `public/service-worker.js` с событиями `install`/`activate`/`fetch`
- [x] Кеширование статики: `/`, `/index.html`, `/manifest.json` (стратегия Cache First)
- [x] Офлайн-режим: загрузка из кеша при отсутствии сети
- [x] Очистка устаревших кешей при обновлении версии
- [x] PWA manifest: `public/manifest.json` + ссылка в `index.html`

- [x] Ленивая загрузка страниц через `React.lazy` + `Suspense`

##  Технологии

| Инструмент | Назначение |
|------------|-----------|
| React 18 + TypeScript | Фронтенд-фреймворк + строгая типизация |
| Vite | Быстрая сборка, HMR, dev-сервер |
| React Router DOM v6 | Маршрутизация + защита роутов (`<ProtectedRoute>`) |
| Context API + `localStorage` | Глобальное состояние + сохранение авторизации и избранного |
| Service Worker API | Кеширование статики + работа в офлайн-режиме |
| PWA Manifest | Установка приложения, тема, иконки, метаданные |
| Fetch API | Асинхронные запросы к внешнему API |
| ESLint + Prettier | Линтинг, форматирование и поддержка качества кода |

##  Тестирование
Быстрая проверка функционала:
□  Открываешь / → редирект на /login (не авторизован)
□  Вводишь test@example.com / 123456 → вход успешен
□  В Navbar:  email + кнопка «Выйти»
□  Нажимаешь «Выйти» → возврат на /login, токен очищен
□  Переходишь на /favorites → список загружается
□  DevTools → Application → Service Workers: активен? 
□  DevTools → Network → Offline → F5: грузится из кеша? 
□  Появляется уведомление « Вы в офлайн-режиме»? 
Если всё ок → переходим к коммиту.
